# Mini Ludo 4×4 🎲

A compact Indian-style Ludo game built with React + Vite.

## Features

- 4 players: Green, Red, Yellow and Blue
- 4×4-style compact board with a 16-cell circular track
- 2 tokens per player
- Roll 6 to enter the board
- Token movement and captures
- Extra turn on rolling 6
- Finish both tokens to win
- Responsive premium glassmorphism UI
- Ready for GitHub and Vercel

## Rules

1. Roll a 6 to bring a token onto the track.
2. Move the token according to the dice.
3. Landing on an opponent captures that token and sends it home.
4. A token needs exactly 12 progress steps to finish.
5. Finish both tokens to win.
6. Rolling a 6 gives another turn.

## Run

```bash
npm install
npm run dev
```
